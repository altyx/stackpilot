# Store screenshots

Captured from the release build against a demo Portainer instance (fictional
homelab data), dark theme, status bar at 9:41. PNG, no transparency.

| Folder                 | Device                | Size (px)   | Store slot                      |
| ---------------------- | --------------------- | ----------- | ------------------------------- |
| [`iphone/`](iphone/)   | iPhone 17 Pro Max     | 1320 × 2868 | App Store — iPhone 6.9" display |
| [`ipad/`](ipad/)       | iPad Pro 13-inch (M5) | 2064 × 2752 | App Store — iPad 13" display    |
| [`android/`](android/) | Android phone (9:16)  | 1080 × 1920 | Google Play — phone screenshots |

The App Store scales the 6.9" and 13" sets down for smaller devices. Google
Play accepts at most 8 phone screenshots: leave out `09-sign-in.png`.
